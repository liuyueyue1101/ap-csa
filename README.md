# AP CSA Foundations Course Site

Static course site prepared for GitHub Pages.

## Curriculum
- Foundation warm-up: 2 weeks
- AP Unit 1: Using Objects and Methods (15–25% MCQ)
- AP Unit 2: Selection and Iteration (25–35% MCQ)
- AP Unit 3: Class Creation (10–18% MCQ)
- AP Unit 4: Data Collections (30–40% MCQ)
- Exam-mode review: current 4-FRQ format + timed MCQ/FRQ

Source of truth: College Board AP Computer Science A Course and Exam Description, effective Fall 2025.

## GitHub Pages
This repository is static. In GitHub: Settings → Pages → Deploy from a branch → main / root.

No build step is required. Open `index.html`.
