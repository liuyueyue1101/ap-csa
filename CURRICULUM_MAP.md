# AP CSA Foundations Course — Curriculum Map

## Delivery cadence

- 3 teaching lessons + 1 practice session per week.
- Sessions are labeled by sequence, not fixed weekdays, so training/travel interruptions can shift the schedule without creating a missed-day problem.
- Student completion is tracked separately from whether materials are ready.

## Phase 1 — Foundation warm-up

Two weeks establish the mental models needed to learn programming: computer/program/application, files and folders, source code and execution, a short Python on-ramp, input, debugging, and a small programming challenge.

The warm-up is deliberately short. Python is used only to reduce syntax load and establish the edit–run–debug loop; Java becomes the primary language for the AP-aligned core.

## Phase 2 — AP CSA core (Fall 2025 framework used for 2026–27)

The site covers every required topic in the four-unit College Board framework:

1. **Using Objects and Methods** — 15–25% of MCQ
2. **Selection and Iteration** — 25–35% of MCQ
3. **Class Creation** — 10–18% of MCQ
4. **Data Collections** — 30–40% of MCQ

Every three teaching lessons are followed by a practice session. Practice sessions emphasize retrieval, tracing, debugging, writing code, and error logging instead of adding new content.

Inheritance is retained only as optional enrichment because it is not a core unit in the current four-unit AP CSA framework.

## Phase 3 — Exam mode

Eight weeks focus on MCQ analysis, the four FRQ types, timed sections, error repair, Bluebook familiarity, Java Quick Reference familiarity, and pacing.

## Free resources embedded in lessons

- College Board AP CSA Course and Exam Description
- College Board AP CSA exam and released FRQs
- CSAwesome2 (current revised curriculum)
- Free AP CSA video tutorials aligned to the 2025 revision
- Selected older video playlists only when the concept still matches; these are identified as older-numbering resources in the course data.

## Design principles

- Student-facing materials are in English.
- Each teaching lesson uses retrieval → mental model → guided explanation → code/model → think question → hands-on activity → AP connection → resources → exit check → homework.
- Each practice session uses retrieval → trace → debug → write → AP-style reasoning → error log → exit check.
- Teacher Notes can be toggled during presentation.
- Slides are one-screen-at-a-time and support keyboard navigation and fullscreen mode.
